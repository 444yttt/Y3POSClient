Bump in-process synthetic location feed

Open 位置テスト inside Bump. Enter latitude,longitude lines, speed(m/s) and accuracy(m). Start/update the feed or stop it inside the same screen. One point is fixed; multiple points follow a great-circle route. Stops at the final point. Injection starts OFF each launch.

This implementation directly substitutes only the two pinned Bump location callbacks and getter paths. Native callback batch cardinality/order/timestamps are retained. Periodic synthetic fixes are delivered only to a Bump manager that requested updates, on its observed delivery loop. Getter and callback fix identity match. Queued updates cannot cross stop/restart generations. Other managers and other apps are unaffected. Stop restores original future callbacks/getter; Bump may retain an old cached position until it reads/receives an update.

Reloc's TargetLocation/NMEA data model is the technical reference: WGS84 coordinates, speed/course and timestamped fixes. Bump consumes CLLocation directly rather than iAP2/NMEA, with speed in m/s instead of NMEA knots. No accessory transport, separate app or MFi identity is used. No Reloc source is incorporated. No global CLLocation getters or provenance methods are overridden. Generated values use the standard public initializer with unspecified sourceInformation; they are test data and are not claimed to be measured GPS.

Startup app-private group fallback supports validated installer team suffixes. Original cross-extension App Group sharing remains unavailable. Native fixture tests do not execute Bump. Real-device launch and scratch-map/server acceptance remain unverified.

Background continuation is an opt-out preference. While the feed is active, an eligible Bump CLLocationManager that requested continuous updates and delivered a native callback is configured to allow background location updates and not pause automatically. Original manager flags are restored when the feed stops or the preference is disabled. The existing host location background mode and OS permission remain necessary. Force-quit/suspension cannot be bypassed; real-device background execution is unverified. No audio keepalive or additional location manager is created.

Local library: named routes, named first-input places, and the latest 100 successful start/update history entries persist in Application Support. Draft fields and the background preference persist, but injection remains OFF after process relaunch. Selecting an entry only fills the form. Entries can be deleted. App removal deletes this local library.

Import from Files accepts UTF-8 TXT/CSV (latitude,longitude), GPX tracks/routes/waypoints, and GeoJSON Point/MultiPoint/LineString/MultiLineString. Files are capped at 2 MB. Separate paths remain selectable. The active route limit is 256 points; oversized paths are rejected without truncating or replacing existing input. Import never starts injection automatically.
