Bump 2.135.0 location debugger

Supported input: Bump 2.135.0, build 261126153935.

Usage:
1. Open Bump and allow its normal location access. The injected control appears at the top right.
2. Open 位置テスト. Enter one latitude,longitude per line. One point holds a fixed position; multiple points play a route.
3. Set speed in metres per second and horizontal accuracy in metres. Tap この座標で注入を開始.
4. Stop with the stop control. Future callbacks and manager reads then use the original app behavior. The app may retain its last position until the next real update.

The debugger starts OFF on every app launch. Synthetic timer delivery starts only after observing the actual manager delegate callback's run loop and while the app has requested ongoing updates. It does not change location permission or other apps' locations.

Generated CLLocation objects explicitly carry isSimulatedBySoftware=YES. Bump reads this field; scratch-map/server acceptance is not established. This tool does not change paid entitlements or scratch counters.

Signing uses a separate bundle identifier. App Group data cannot be shared with the original app; the main app uses an app-private container for group.co.amo if the original group is unavailable. KEYCHAIN_SHARED_GROUP is mapped only to a keychain group permitted by the selected profile.

Native fixtures validate callback substitution, route calculations, stop restoration, forwarded callback identity and periodic delivery. These checks do not execute the real Bump app. Real-device installation, launch, login persistence, background operation, extensions and scratch-map results are unverified.
