Bump 2.135.0 — native system location input

Install the official Reloc app separately using your normal signing/install process. Configure and start the location in Reloc, confirm its Core Location telemetry, then return to Bump. Stop and restore location from Reloc.

Bump receives iOS Core Location unchanged. This build does not alter coordinates, timestamps, accuracy, speed/course or source flags, and does not synthesize timer callbacks. The old injection entry point always rejects activation. The position shown by iOS may come from an external accessory; it is not claimed to be built-in GPS measurement.

Startup app-private App Group fallback supports the delivery identifier plus a validated signing-team suffix. Original App Group cross-extension sharing remains unavailable. Real-device launch and scratch behavior are unverified.
